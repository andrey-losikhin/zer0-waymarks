# Замысел zer0-waymarks

## Проблема

Закладки разнесены по Firefox, Chromium и их форкам. Добавленная в одном браузере
закладка не появляется в остальных без разных облачных аккаунтов и сервисов.

## Пользовательский сценарий

```text
SUPER+B -> найти "документация" -> Firefox Work -> Enter
```

Добавленная в папку `Waymarks` браузерная закладка отправляется в локальную базу.
Остальные запущенные браузеры получают её при следующем pull, незапущенные — при
старте. Noctalia всегда ищет непосредственно в канонической базе.

## MVP

- локальная база с CRUD, папками и поиском;
- launcher `/wm` и отдельная панель;
- выбор браузера и профиля;
- ручное добавление URL и импорт Netscape Bookmarks HTML;
- Firefox bridge;
- Chromium bridge;
- синхронизация только выделенной папки `Waymarks`;
- tombstones, conflict report, backup и dry-run reconcile;
- Arch package и понятная установка Native Messaging manifests.

## Не входит

- пароли и автозаполнение форм — это зона `zer0-waypass`;
- прямое редактирование файлов браузерных профилей;
- синхронизация всего дерева закладок;
- мобильные браузеры;
- публичный sync-сервер и web UI;
- история посещений, cookies, вкладки и содержимое страниц;
- гарантированная мгновенная доставка в закрытый браузер.

## После MVP

- Git over SSH для зашифрованного/приватного remote пользователя;
- несколько устройств и deterministic conflict resolution;
- мобильный read-only интерфейс;
- объединённая панель Waypass + Waymarks без объединения хранилищ.
